## Scope 範圍

Only the browser front end is published. The analytical cross-section solver, the Ansys Q2D
Extractor integration, the EDB/ODB++ reader and cutout, the DOE and surrogate modelling, the
residual diagnosis and the identifiability analysis are a private back end and are not
included. The front end on its own cannot run a calibration.

僅公開瀏覽器前端。解析截面求解器、Ansys Q2D Extractor 整合、EDB／ODB++ 讀取與裁切、
DOE 與代理模型、殘差診斷與可辨識性分析屬於私有後端，未收錄於此。只有前端無法執行
任何校正。

No client designs, board data, measured S-parameters or licence configuration are included.
Every number quoted in the documentation comes from synthetic test data whose ground truth
was generated by Ansys Q2D Extractor, not from any real design.

不含任何客戶設計、板檔、實測 S 參數或授權設定。文件中引用的每一個數字都來自合成的
測試資料，其真值由 Ansys Q2D Extractor 產生，並非來自任何真實設計。
